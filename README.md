# 📱 Pokédex

Una aplicación móvil desarrollada en **Flutter** que consume la **PokeAPI** utilizando **GraphQL** para explorar información de Pokémon con filtros avanzados.  
El proyecto sigue los principios de **Clean Architecture** y utiliza **BLoC** como gestor de estado, garantizando escalabilidad, mantenibilidad y separación de responsabilidades.

---

## 🚀 Características

- 🔍 **Explorar Pokémon**: Consulta información detallada de cada Pokémon.  
- ⚡ **Filtros avanzados**: Gracias a **GraphQL**, la app permite aplicar filtros personalizados sobre los datos de la PokeAPI.  
- 🎨 **Temas dinámicos**: Implementación de **light/dark theme** para mejorar la experiencia del usuario.  
- 🏛️ **Arquitectura limpia**: Aplicación estructurada bajo **Clean Architecture** con separación en capas (data, domain, presentation).  
- 🔄 **Gestión de estado con BLoC**: Patrón probado para el manejo eficiente de estados y eventos de la aplicación.  

---

## 🛠️ Tecnologías utilizadas

- **Flutter** (UI y lógica principal)  
- **BLoC** (gestión de estado)  
- **Clean Architecture** (organización del proyecto)  
- **GraphQL** (consultas a la PokeAPI con filtros)  
- **PokeAPI** (fuente de datos)
